# Frontend (Angular) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Angular admin panel: order list with filters, order detail with event timeline, and dashboard with status counts and revenue.

**Architecture:** Angular 22 SPA in `frontend/`. Three route-level components. HTTP calls to order-service (:8081) and payment-service (:8082). Static JWT token in `environment.ts` for dev (no login screen). Angular Material for UI components.

**Tech Stack:** Angular 22, Angular Material, Angular Router, HttpClient, RxJS, TypeScript

**Spec:** See technical refinement — Angular section: 3 views, routes, services, timeline data sources.

## Global Constraints

- Work inside `frontend/` directory; run `ng serve` to test; run `ng build` to verify no compile errors
- API base URLs from `environment.ts`: `orderServiceUrl: 'http://localhost:8081'`, `paymentServiceUrl: 'http://localhost:8082'`
- JWT token hardcoded in `environment.ts` as `adminToken: 'REPLACE_WITH_TOKEN_FROM_LOGIN'`
- All HTTP calls go through `AuthInterceptor` which adds `Authorization: Bearer {token}` and `X-Correlation-Id` (generate UUID per request)
- No login screen — token is set manually in environment.ts from a Postman call to `/api/v1/auth/login`
- Use Angular standalone components (Angular 22 default)
- Install Angular Material: `ng add @angular/material` before Task 2
- Currency display: Brazilian Real (BRL), `pt-BR` locale

## Review Focus

- **CORS:** order-service and payment-service must have CORS configured to allow `http://localhost:4200`; if requests fail in browser with CORS error, add `@CrossOrigin` to controllers or configure `CorsConfigurationSource` in SecurityConfig
- **HttpClient in standalone:** must add `provideHttpClient(withInterceptors([authInterceptor]))` to `app.config.ts`
- **Empty state:** order list and dashboard must render correctly when API returns empty page/zero counts — no blank screen or uncaught errors
- **Observable unsubscribe:** use `AsyncPipe` in templates to avoid memory leaks; avoid manual `subscribe` without `takeUntilDestroyed`
- **Angular Material theme:** run `ng add @angular/material` and choose a prebuilt theme; do not write custom SCSS from scratch

Timeline building logic:
```typescript
buildTimeline(order: Order, payment: Payment | null): TimelineEvent[] {
  const events: TimelineEvent[] = [
    { label: 'Pedido criado', date: order.createdAt, status: 'done' }
  ];
  if (order.status === 'PAID' && payment) {
    events.push({ label: 'Pagamento aprovado', date: payment.createdAt, status: 'done' });
  } else if (order.status === 'PAYMENT_FAILED' && payment) {
    events.push({ label: 'Pagamento falhou', date: payment.createdAt, status: 'error' });
  } else if (order.status === 'CANCELLED') {
    events.push({ label: 'Pedido cancelado', date: order.updatedAt, status: 'error' });
  } else {
    events.push({ label: 'Aguardando pagamento', date: '', status: 'pending' });
  }
  return events;
}
```
